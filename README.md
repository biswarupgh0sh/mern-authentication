## Setup .env
```bash
PORT = 5000
MONGO_URI =
JWT_SECRET =
NODE_ENV =development

MAILTRAP_TOKEN=

MAILTRAP_WELCOME_AFTER_AUTH_UUID=

CLIENT_URL=
```

## Run this app locally
```bash
npm run build
```

## Start the app
```bash
npm run start
```
